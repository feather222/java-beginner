## 🚀 如何运行

```bash
# 克隆仓库
git clone https://github.com/feather222/python-beginner.git
cd python-beginner

# 直接运行某一天的代码（以第 1 天为例）
python Day001-020/date001.py
```

> 💡 **提示**：Day 26 起的代码依赖第三方库，运行前请先安装：
> `pip install openpyxl python-docx PyPDF2 pillow requests`
